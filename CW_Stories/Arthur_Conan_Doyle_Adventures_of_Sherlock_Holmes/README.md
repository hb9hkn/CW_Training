# 🧠📻 CW Training Resources

Welcome to the **CW Training** project! This repository provides two types of practice materials to help you improve your Morse code listening skills.

---

## 📖 Stories in CW

A growing collection of **short stories converted into CW audio**, sourced from [Project Gutenberg – Free eBooks](https://www.gutenberg.org/).

### ⚖️ Preprocessing:
- Special characters are stripped and replaced with basic punctuation to improve readability.
- Files are provided at **five different speeds**, starting from beginner-friendly to more advanced.

### 🏁 Training Method:
1. Start at the speed where you can understand **at least 80%** of the text.
2. Stories are broken into **5–10 minute segments**.
3. Each segment increases in speed slightly (by **0.01–0.02 WPM**).
4. Repeat a segment as often as needed before advancing.

---

## 🗜️ How to Unpack the Stories

1. 📥 Download the `.zip` archive of the story.
2. 📂 Extract all files to a **local folder**.
3. 🧩 Inside, you'll find another `.zip` – extract that too.
4. 🎶 You’ll end up with several `.mp3` files.
5. 🎧 Play them using any **MP3 player or mobile app** of your choice.
